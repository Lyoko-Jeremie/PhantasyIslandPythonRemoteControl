# PhantasyIsland Java Remote Control

## Build with Gradle

This project keeps Java sources in:

- `PhantasyIslandJavaRemoteControl/`

The Gradle build is configured to compile directly from that directory.

### Compile

```powershell
gradle clean compileJava
```

If you use IntelliJ's bundled Gradle, import this folder as a Gradle project and run `compileJava`.
