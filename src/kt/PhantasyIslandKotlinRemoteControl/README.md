# PhantasyIslandKotlinRemoteControl

This folder is now a standalone Kotlin JVM project that can be compiled with Gradle.

## Requirements

- JDK 17+
- Gradle 8+

## Compile

```powershell
Set-Location "E:\Code\PythonProject\PhantasyIslandPythonRemoteControl\src\kt\PhantasyIslandKotlinRemoteControl"
gradle build
```

## Compile only (faster)

```powershell
Set-Location "E:\Code\PythonProject\PhantasyIslandPythonRemoteControl\src\kt\PhantasyIslandKotlinRemoteControl"
gradle compileKotlin
```

> Note: this project currently defines library-style APIs and one demo entry (`radio/DebugRadio.kt`).
